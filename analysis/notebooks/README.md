# คู่มือวิเคราะห์ artifact รอบ pedicle screw (สำหรับ Windows)

คู่มือนี้สำหรับผู้ที่ไม่ถนัดเขียนโปรแกรม การวิเคราะห์ทั้งหมดอยู่ใน notebook `pedicle_screw_analysis.ipynb` ซึ่งทำทีละขั้น และมีคำอธิบายภาษาไทยทุกขั้น

## 1. ติดตั้ง (ทำครั้งเดียว)

1. **ติดตั้ง Miniforge** (โปรแกรมจัดการ Python)
   - ดาวน์โหลดจาก https://conda-forge.org/download/ แล้วเลือกตัวติดตั้งของ Windows
   - ติดตั้งด้วยค่าเริ่มต้นทั้งหมด (เลือก "Just Me")
2. **ดาวน์โหลดโค้ด** จาก GitHub
   - กดปุ่ม `Code` → `Download ZIP` แล้วแตกไฟล์ไว้ในที่ที่หาง่าย เช่น `C:\TONIQ\toniq`
3. **ติดตั้งเครื่องมือ**
   - เปิดโฟลเดอร์ `analysis` แล้วดับเบิลคลิกไฟล์ `install_windows.bat`
   - รอประมาณ 5–15 นาที จนขึ้นข้อความ `Installation complete`

## 2. เปิดใช้งาน (ทุกครั้งที่จะวิเคราะห์)

1. ดับเบิลคลิก `analysis\start_notebook.bat` แล้ว notebook จะเปิดในเว็บเบราว์เซอร์
2. ทำตามขั้นใน notebook จากบนลงล่าง โดยกด **Shift + Enter** เพื่อรันทีละช่อง
3. เมื่อเสร็จ ให้ปิดเบราว์เซอร์และปิดหน้าต่างสีดำ

## 3. คำแนะนำการสแกน phantom กับ pedicle screw

### หลักการ: เปรียบเทียบเป็นคู่

ทุกการวัดต้องเทียบภาพ "สกรูพลาสติก" กับ "สกรูโลหะ" ที่วางอยู่ในตำแหน่งเดียวกันทุกอย่าง

- **สกรูพลาสติก:** พิมพ์ 3D ให้รูปร่างเหมือนสกรูจริง (รวมเกลียว) เพื่อให้แทนที่น้ำได้ปริมาตรเท่ากัน
- **การเปลี่ยนสกรู:** phantom ควรมีตัวยึดที่ถอดเปลี่ยนสกรูได้โดยไม่ต้องขยับกล่อง

### ชุดภาพที่ต้องสแกน (ต่อหนึ่ง protocol และหนึ่งแนวการวางสกรู)

| ลำดับ | phantom | สกรู | หมายเหตุ |
|---|---|---|---|
| 1 | structured (lattice) | พลาสติก | **เริ่มด้วยพลาสติกเสมอ** |
| 2 | structured | พลาสติก ความละเอียดสูง | สำหรับ SR (ไม่บังคับ) |
| 3 | structured | โลหะ | |
| 4 | uniform | พลาสติก | |
| 5 | uniform | โลหะ | |
| 6 | uniform | โลหะ (สแกนซ้ำทันที) | สำหรับ SNR |
| 7 | structured | พลาสติก (ซ้ำตอนท้าย) | ใช้ตรวจว่า phantom ขยับหรือไม่ |

### การตั้งค่าบนเครื่อง Philips

- **prescription:** ใช้ FOV, matrix, ความหนา slice และตำแหน่งเดียวกันทุก series (copy prescription) และห้าม re-localize ระหว่าง session
- **การ export:** ส่งออกเฉพาะภาพ **magnitude** เท่านั้น
- **reconstruction voxel:** ตั้งให้เท่ากับ acquisition voxel ถ้าทำได้ เพื่อให้การวัด SR ถูกต้อง
- **การแก้ความสม่ำเสมอของสัญญาณ (CLEAR/SENSE) และ denoise:** ตั้งเหมือนกันทุก series

### ตัวแปรที่น่าศึกษาสำหรับ pedicle screw

- **แนวสกรูเทียบกับสนามแม่เหล็ก (B0):** วางขนานกับ B0 และตั้งฉากกับ B0 ปัจจัยนี้มีผลต่อขนาด artifact มาก
- **ทิศ frequency encoding:** สลับให้ตามแนวสกรูกับขวางแนวสกรู
- **วัสดุสกรู:** เช่น titanium alloy กับ cobalt-chrome หรือ stainless steel
- **protocol:** TSE ปกติ, TSE ที่เพิ่ม bandwidth, และ Philips **O-MAR** / **O-MAR XD**

แต่ละเงื่อนไขต้องสแกนชุดคู่พลาสติก/โลหะของตัวเอง แล้วรัน notebook แยกกันโดยใช้ `RESULTS_FOLDER` คนละโฟลเดอร์ จากนั้นนำตัวเลขใน `summary.csv` ของแต่ละเงื่อนไขมาเปรียบเทียบกันใน Excel

## 4. ผลลัพธ์ที่ได้

| ไฟล์ | ความหมาย |
|---|---|
| `summary.csv` | ตัวเลขสรุป: ปริมาตรสัญญาณหายและสัญญาณกองรวม (mL), การเลื่อนสูงสุด (mm), SNR และ FWHM |
| `overview.png`, `ia_*.png`, `gd_*.png`, `snr_*.png`, `sr_*.png` | รูปสำหรับใส่ในรายงานหรือสไลด์ |
| `zonal_summary.csv`, `zonal_summary.png`, `zones_*.png` | ผลแยกตามระยะห่างจากผิวสกรู (zone) รวม SSIM (ขั้นที่ 9) |
| `comparison.csv`, `comparison.png` | เปรียบเทียบหลายเงื่อนไข (ขั้นที่ 10) |
| `*.npy` | ข้อมูล map ทั้งหมด สำหรับวิเคราะห์เพิ่มเติมภายหลัง |

### หมายเหตุเรื่อง SSIM

SSIM คำนวณแบบเดียวกับ `viqa` (ค่าตรงกันทุกตำแหน่งทศนิยม) แต่ใช้ `skimage.metrics.structural_similarity` เพราะให้ SSIM map ทั้งภาพ จึงเฉลี่ยแยกตาม zone ได้ ส่วน `viqa` ให้ค่าเฉลี่ยของทั้งภาพเพียงค่าเดียว จึงไม่ต้องติดตั้ง `viqa` เพิ่ม

ใน `viqa` และ `skimage` เมื่อใช้ Gaussian window (ค่าเริ่มต้น) ค่า `win_size` จะไม่มีผลต่อตัวกรอง ขนาดหน้าต่างถูกกำหนดด้วย `sigma` เท่านั้น

## 5. ข้อจำกัด

- เครื่องมือนี้ใช้เพื่อการวิจัยเท่านั้น ไม่ใช่เพื่อการวินิจฉัย
- ค่า SR ที่เป็น 0 หรือบริเวณว่างในรูป หมายถึงบริเวณที่วัดไม่ได้ (ใกล้สกรูหรือมี artifact มาก) ไม่ได้แปลว่าความละเอียดดีมาก
- ถ้าใช้งานงานวิจัยนี้ กรุณาอ้างอิง: Toews AR, et al. Magn Reson Med. 2024. doi: 10.1002/mrm.30222
